# 免费语音候选

目前软件实际接入的提供者仍是 Edge。下面是候选调查，不表示已安装、测速、试听或支持页面切换。模型开放权重不等于云 API 免费；本地推理免按字计费，但需要下载、算力、存储和维护。

| 候选 | 适合尝试的原因 | 重要边界 |
|---|---|---|
| Qwen3-TTS | 中文与预设角色音色；1.7B CustomVoice 有指令风格控制，适合研究语气表达 | 0.6B 更适合先做硬件试跑，但官方功能表未将它列为指令控制版本；不要承诺与 1.7B 一样的导演能力 |
| Kokoro-82M-v1.1-zh | 轻量中文候选，82M 参数，适合优先考虑资源占用 | 轻量不等于真人感更强；其模型卡也未宣称是所有能力的全面升级 |
| CosyVoice | 中文合成、参考音频与表达控制路线，可作为第二轮对照 | 环境和参考声音准备较复杂，克隆参考必须得到授权 |

来源：[Qwen 官方仓库与功能表](https://github.com/QwenLM/Qwen3-TTS)、[Kokoro 中文模型卡](https://huggingface.co/hexgrad/Kokoro-82M-v1.1-zh)、[CosyVoice 官方仓库](https://github.com/FunAudioLLM/CosyVoice)。各版本分别核对代码、权重与音色的许可证，不把某个代码仓库的许可证自动套到任意第三方声音。

## 建议的实际筛选方法

先用 Edge 作为基线，对同一段 60–90 秒原创教学对话做盲听：含一句疑问、一次犹豫后解释、一段英文术语、数字／公式以及一次角色切换。先对比 Qwen3-TTS 0.6B 和 Kokoro 中文版；算力允许时再测 Qwen 1.7B 的指令控制。这个顺序是工程选择，不是音质排行榜。

分别评分：自然度、疑问语调、句内停顿、中文与英文发音、角色可区分程度、是否漏字／重复、听久是否疲劳。同时测峰值显存、加载时间、每分钟音频生成耗时和失败率。短样本胜出后再做 5–10 分钟连续试播，最后才生成整期 30–60 分钟节目。

## 接入时保留的规范

继续复用证据底稿、口语化脚本、角色意图、术语词典和按语义分段。不同引擎分别映射语气与停顿，不能机械照搬 Edge 的 Hz／百分比参数，也不要把句子切得过碎而失去上下文。保留片段缓存、失败续做、实际时长与解码检查，不能用重复内容填满时长。

不默认克隆真人，不模仿参考讲解者的人声。采用模型原生预设或获授权声音，所有节目保留 AI 生成披露。部署候选应使用独立虚拟环境，避免破坏现有可用网页与 Edge 环境。
