# 论文开讲 V3

把 PDF、HTML 和文章／Notion 链接变成有证据定位的精读报告、教学脚本与可选音频／解释动画。提供两种生成方式：Codex 接力，或 Kimi / 兼容 API 自动制作。它们共用 V3 研究契约；API 模式当前只读取文本，不等同于包含图表视觉核验的完整精读。

## 日常使用

本地开发与日常运行统一使用 GitHub 文件夹下的 `paper-dialogue-studio` 仓库。请在 Codex 中打开这个仓库目录；旧“音频生成”目录仅保留兼容入口，不再独立维护。源码、配置和规范更新后先验证，再做本地 commit，默认不 push。真实材料、历史节目和迁移备份继续仅保存在本机。

1. 双击 `启动论文开讲.cmd`；或运行 `powershell -ExecutionPolicy Bypass -File .\start-web.ps1`。
2. 拖入一篇或多篇 PDF／HTML，或输入文章／Notion 链接。可补充共同研究问题、基础、深度、单人／双人、时长、动画选择。
3. 选择生成方式。默认“Codex 接力”：点击“保存任务并交给 Codex”，把指令发到本项目的对话中，同一对话也可以。选择“API 自动制作”则填写密钥、确认发送材料与计费后直接启动，不需要复制指令。
4. 网页会读取任务文件并刷新阶段。完成后在同一链接查看精读报告、研究推进计划、学习卡、脚本、动画和已生成的 MP3。
5. 失败会保留原因和阶段产物。Codex 模式重新提交继续指令；API 模式可重新配置后点击继续，会复用相同模型与输入对应的有效缓存，但新请求仍可能计费。关闭网页不删除材料。

网站只监听 `127.0.0.1:7860`。所有页面关闭后约 40 秒退出网站服务，不设置开机启动。API 任务随服务停止，已发给提供方的请求不保证能取消计费；Codex 任务独立运行，不会因关网页自动取消。再次双击启动文件恢复查看。只打开旧 localhost 地址不能启动已退出的本地进程。

首次缺依赖时运行 `setup.ps1`。Codex 接力不需要单独 API Key；API 模式使用提供方的密钥及独立账单。语音仍由 Edge 合成，需要联网。私有 Notion 在 Codex 模式使用已授权连接，在 API 模式使用页面已共享的 Integration Token。

读者基础可选：零基础入门、跨专业读者（默认）、本专业本科生、研究生／研究人员、领域专家、自定义。该选择影响先修知识、术语与公式解释的起点，不降低证据核验标准；研究深度和节目时长仍可分别设置。

无论基础档位，均默认听众没有读过原文。新节目先由主讲介绍工作题名、第一／共同第一作者、通讯作者、对应单位和研究目标／方法／结果及边界，再开始提问式精讲；未核实身份明确说明，不凭作者排序或名气猜测。旧音频不自动改写，需要重制时另存版本。

## 本次功能升级

| 模块 | 已实现 | 仍需人工／研究判断 |
|---|---|---|
| 收件 | 多文件、补充链接、独立任务、文件校验、失败恢复 | 确定材料是不是原文，Notion 访问授权 |
| 读取 | PDF 逐页文本、HTML 结构／引用／图片索引、低文本页警告 | OCR、公式／图表视觉核验，动态网页正文读取 |
| 精读 | 三遍／八类追问／学科检查的数据契约与引用校验 | 真正读懂方法、核对论断、判断证据强弱 |
| 综合 | 单一证据底稿、逐篇与跨篇比较、公开版本检索记录 | 合法版本身份、可比性、分歧与未知项 |
| 教学 | 章节问题、例子、预测、自测与论断绑定 | 选好例子、避免跳步、确保两人对话推进理解 |
| 报告 | 章节定位、专注／大字阅读、移动目录、打印样式、Markdown、研究计划、学习卡、脚本派生 | 内容复核后才允许发布 |
| 音频 | 短样本、混排时长估计、参数缓存、拼接平滑、解码、时长与版本门禁 | 发音、自然度和术语需实际试听；尚无自动 ASR |
| 画面 | 克制编辑式页面、离线步进讲解、预测揭示、证据入口、演示视图 | 非 MP4 或自动配音同步，不虚构物理仿真 |
| 发布 | 版本哈希、旧音频拒绝、任务进度与重试 | 未完成用户请求的媒体不能标为完成 |

固定执行规范：[WORKFLOW.md](WORKFLOW.md)；视觉与讲解：[DESIGN.md](DESIGN.md)；参数：`config/podcast.yaml`、`config/research.yaml`、`config/pronunciation.yaml`。历史节目不自动迁移。

网页与演示的 [GitHub 设计参考库](docs/DESIGN_REFERENCES.md) 保存四个万星项目的来源、核验快照、适用规则与许可边界；本项目没有复制其安装器或增加在线依赖。入口页的“调整制作偏好”可展开深度、形式、时长与音频选项，折叠时保留当前选择。点击“体验 V3”可查看新版报告与逻辑演示；旧任务的已发布产物保持原样。

## 开发验收

```powershell
.\.venv\Scripts\python.exe -B -m unittest discover -s tests -p "test_*.py"
.\.venv\Scripts\python.exe -B scripts/package_repo.py --check
```

浏览器回归：`tests/check_web.cjs` 和 `tests/check_visual.cjs`；`tests/check_lifecycle.cjs` 验证多页面保活与全部关闭后退出，约需两分钟。参数依次为现有 Node 包目录与可选 Chromium／Edge 可执行路径；不会自动下载浏览器。使用隔离测试任务，音频测试使用测试音，不调用在线 TTS。结果截图保存在 `tests/screenshots/`。

页面示例是工作流演示，不是真实论文，也没有伪造音频。真实科学理解和声音自然度应在下一次论文任务中进一步验收。
